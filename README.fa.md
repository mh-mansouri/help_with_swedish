# کمک به زبان سوئدی — یک Claude Skill

[فارسی](README.fa.md) · [English](README.md) · [Svenska](README.sv.md)

یک Claude Skill برای کمک به زبان‌آموزان سوئدی در پیدا کردن کلیپ‌های یوتیوب و پادکست‌های مناسب با سطح و هدف یادگیریشان.

بیشتر راهنمایی‌های یادگیری زبان یا خیلی کلی هستند یا خیلی شلوغ. این Skill با پرسیدن سطح کاربر و هدف او، پیشنهادهای دقیق‌تر و کاربردی‌تری ارائه می‌دهد.

## سطوح A1 تا C2 یعنی چه؟

این‌ها سطوح CEFR هستند، مقیاس استاندارد اروپایی (که در دوره‌های SFI هم استفاده می‌شود) برای توصیف میزان تسلط شما به یک زبان. اگر مطمئن نیستید کدام سطح مناسب شماست، فقط بگویید — Skill، پرامپت و صفحه وب همگی با چند سؤال کوتاه سطح شما را مشخص می‌کنند.

| سطح | مرحله | چه کارهایی از شما برمی‌آید |
|---|---|---|
| A1 | مبتدی | درک و استفاده از عبارات بسیار ساده. معرفی خود و پرسیدن سؤالات ساده. |
| A2 | مقدماتی | انجام تعاملات ساده روزمره مانند خرید، پرسیدن آدرس و کارهای روتین. |
| B1 | متوسط | مدیریت بیشتر موقعیت‌ها هنگام سفر یا کار. توصیف تجربیات و برنامه‌ها. |
| B2 | متوسط رو به بالا | تعامل روان با افراد بومی‌زبان. درک ایده‌های اصلی متون پیچیده. |
| C1 | پیشرفته | بیان روان و خودجوش درباره موضوعات دانشگاهی یا حرفه‌ای دشوار. |
| C2 | مسلط | درک تقریباً همه‌چیزی که می‌شنوید یا می‌خوانید، با تسلطی نزدیک به زبان مادری. |

## همین حالا امتحان کنید — در هر چت هوش مصنوعی کار می‌کند

نیازی به دانلود یا نصب نیست. متن داخل کادر را کپی کنید، آن را به‌عنوان اولین پیام در ChatGPT، Gemini، Claude، Copilot یا هر چت هوش مصنوعی دیگری paste کنید، سپس سؤال خود را بپرسید. متن داخل کادر دستورالعملی برای هوش مصنوعی است و به همین دلیل به انگلیسی نوشته شده، اما هوش مصنوعی همچنان به فارسی (یا هر زبانی که شما بنویسید) پاسخ می‌دهد.

متن کامل را در [universal-prompt.md](universal-prompt.md) ببینید (همان محتوای README انگلیسی).

## بدون نیاز به حساب کاربری — صفحه‌ای با چت زنده، یا بدون هوش مصنوعی

نمی‌خواهید یک Skill نصب کنید یا پرامپتی را کپی-پیست کنید؟ این صفحه وب چت زنده خودش را دارد، بنابراین می‌توانید مستقیماً از آن سؤال بپرسید — یا هوش مصنوعی را کاملاً کنار بگذارید و سطح و مهارت خود را از یک لیست ساده انتخاب کنید. به سوئدی (پیش‌فرض)، انگلیسی و فارسی در دسترس است — با دکمه‌های بالای صفحه هر زمان زبان را عوض کنید، با چیدمان راست‌به‌چپ برای فارسی:

- نسخه زنده: https://mh-mansouri.github.io/help_with_swedish/
- یا [docs/index.html](docs/index.html) را دانلود کنید و در هر مرورگری باز کنید — بدون سرور، بدون نصب، بدون ثبت‌نام.

![گیف نمایشی چت: یک زبان‌آموز برای صحبت‌کردن کمک می‌خواهد و یک برنامه با ویدیوهای واقعی و لینک‌دار دریافت می‌کند](assets/chat-demo.gif)

هم چت و هم لیست ساده، همان [API زنده](#api-زنده) توضیح داده‌شده در پایین را فراخوانی می‌کنند، بنابراین نتایج با آنچه Skill و پرامپت کپی-پیست پیشنهاد می‌دهند یکسان است. چت روی OpenRouter اجرا می‌شود، با یک مدل رایگان پشتیبان در صورتی که مدل اصلی در دسترس نباشد — برای نحوه اتصال آن و اجرای نمونه خودتان به [`POST /chat`](api/README.md#post-chat) مراجعه کنید.

## نصب به‌عنوان یک Claude Skill دائمی

اگر می‌خواهید هر بار متن را paste نکنید و به‌جایش در Claude به‌صورت خودکار فعال شود: این روش به حساب Claude Pro، Max، Team یا Enterprise نیاز دارد — Skills در پلن رایگان در دسترس نیست.

1. [swedish_mentor.skill](swedish_mentor.skill) را دانلود کنید.
2. در [claude.ai](https://claude.ai)، روی نام خود در پایین سمت چپ کلیک کنید و **Settings** را انتخاب کنید. صفحه **Skills** را زیر Customize باز کنید:

   ![منوی Settings با گزینه Skills هایلایت‌شده زیر Customize](assets/install-steps/1-settings-skills.png)

3. روی **Add skill** و سپس **Upload a skill** کلیک کنید:

   ![منوی Add skill شامل Create with Claude، Write skill instructions و Upload a skill](assets/install-steps/2-add-skill-menu.png)

4. فایل دانلودشده `swedish_mentor.skill` را روی کادر آپلود بکشید (یا برای انتخاب فایل کلیک کنید) و تأیید کنید:

   ![پنجره Upload skill با یک ناحیه drag-and-drop](assets/install-steps/3-upload-dialog.png)

5. یک چت جدید شروع کنید و برای مثال این سؤال را بپرسید: «من در سطح A2 هستم و می‌خواهم قبل از سفر به سوئد صحبت کردنم را بهتر کنم.»

اگر می‌خواهید به‌جای استفاده از فایل آماده، خودتان بسته را بسازید:

```bash
python package_skill.py
python package_skill.py --check
python package_skill.py --install --skills-dir <path-to-skills-folder>
```

دستور `--check` قبل از استفاده از بسته، وجود فایل‌های لازم را بررسی می‌کند.

## دمو

یک کاربر می‌گوید: «من در سطح A2 هستم و می‌خواهم قبل از سفر به سوئد صحبت کردنم را بهتر کنم.» Skill با یک برنامه کوتاه، چند ویدیو یا پادکست مرتبط و یک قدم بعدی روشن پاسخ می‌دهد.

![انیمیشن دمو](assets/skill-demo.gif)

## این Skill چه کاری انجام می‌دهد

- مسیر یادگیری را بر اساس سطح، هدف و مهارت انتخاب می‌کند.
- ویدیوهای یوتیوب و اپیزودهای پادکست را برای گوش دادن، خواندن، نوشتن و صحبت کردن پیشنهاد می‌دهد.
- کانال‌های کاربردی مانند Peter SFI، Lätt Svenska med Oskar، UR Play و Swedish Shadowing، و همچنین پادکست‌هایی مانند Radio Sweden på lätt svenska، Klartext و Fluent Fiction – Swedish را در اولویت قرار می‌دهد.
- راهنمایی‌ها را کوتاه، Encouraging و قابل دنبال کردن نگه می‌دارد.

## چرا این Skill وجود دارد

بسیاری از زبان‌آموزان وقت خود را در ویدیوهای بی‌ربط یا بیش از حد سخت/آسان هدر می‌دهند. این Skill کمک می‌کند تا انتخاب‌ها دقیق‌تر و مسیر یادگیری واقعی‌تر باشد.

## API زنده

همین پیشنهادها به‌صورت یک REST API نیز در دسترس است، که روی Render مستقر شده:

- آدرس پایه: https://help-with-swedish-api.onrender.com
- مستندات تعاملی: https://help-with-swedish-api.onrender.com/docs

روی نسخه رایگان اجرا می‌شود، بنابراین بعد از عدم فعالیت خاموش می‌شود — اولین درخواست بعد از مدتی ممکن است حدود ۵۰ ثانیه طول بکشد. شامل `POST /chat` است، مربی که از طریق Claude Sonnet 5 روی [OpenRouter](https://openrouter.ai) خودش صحبت می‌کند، با یک مدل رایگان (Gemma 4 31B گوگل) به‌عنوان پشتیبان خودکار در صورتی که مدل اصلی اعتبار نداشته باشد یا با محدودیت نرخ مواجه شود — تا زمانی که یک استقرار مقدار `HWS_OPENROUTER_API_KEY` را تنظیم نکند، خاموش است (یک نام با پیشوند مخصوص این پروژه، نه نام عمومی خود OpenRouter، تا هرگز با کلید یک برنامه دیگر قاطی نشود). برای endpoint ها و راه‌اندازی محلی به [api/README.md](api/README.md) مراجعه کنید.

## نحوه استفاده

از متن‌های زیر استفاده کنید:

- «می‌خواهم بهبود Listening سوئدی ام را برای مکالمات روزمره شروع کنم.»
- «من مبتدی هستم و می‌خواهم یک برنامه ساده برای صحبت کردن داشته باشم.»
- «برای تمرین خواندن در سطح B1، ویدیوهای خوب سوئدی پیشنهاد بده.»
- «یک پادکست سوئدی برای رفت‌وآمدم پیشنهاد بده.»
- «می‌خواهم یک برنامه دو هفتگی برای یادگیری سوئدی برای کار داشته باشم.»
- «من در سطح A2 هستم و می‌خواهم دایره واژگانم را قبل از مهاجرت به سوئد بهتر کنم.»
- «من فکر می‌کنم در سوئدی intermediate هستم، اما مطمئن نیستم واقعاً در کجا قرار می‌گیرم.»

یک پاسخ خوب معمولاً شامل این موارد است:

- یک ارزیابی کوتاه از سطح یا یک پیشنهاد مرتبط،
- ۳ تا ۵ ویدیو، پلی‌لیست یا اپیزود پادکست،
- و یک قدم بعدی واضح برای کاربر.

یک مثال قوی به این شکل است:

> «به نظر می‌رسد شما در سطح A2 هستید. یک قدم بعدی خوب، تمرین گوش دادن و تمرین‌های کوتاه صحبت کردن است. من سه ویدیوی کوتاه و یک برنامه روزانه ساده پیشنهاد می‌کنم.»

## این Skill چه کمکی می‌کند

- انتخاب یک قدم بعدی خوب برای یادگیری سوئدی
- تطبیق کاربر با مسیر مناسب بر اساس سطح
- پیشنهاد منابع عملی یوتیوب و پادکست بدون اینکه کاربر را overwhelmed کند

## این Skill جایگزین چه چیزی نیست

- ارزیابی رسمی زبان
- تست سطح توسط معلم
- امتیاز قطعی CEFR
