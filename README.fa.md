# کمک به زبان سوئدی

یک Claude Skill برای کمک به زبان‌آموزان سوئدی در انتخاب کلیپ‌های یوتیوب مناسب با سطح و مسیر یادگیری.

## مرور کلی

این مخزن، Skill و فایل‌های پشتیبان را برای پیشنهاد منابع آموزشی سوئدی بر اساس سطح CEFR و مهارت بسته‌بندی می‌کند.

## ساختار

- hjälp_om_svenska/SKILL.md — دستورالعمل‌های Skill
- hjälp_om_svenska/references/ — فایل‌های مرجع پشتیبان
- hjälp_om_svenska.skill — بسته‌ی آماده‌ی Skill

## نحوه استفاده

1. Skill را با استفاده از فایل package_skill.py بسته‌بندی کنید.
2. آن را در Claude یا محیط سازگار دیگری استفاده کنید.
3. هدف یادگیری زبان خود را توضیح دهید تا کلیپ‌ها و مسیر یادگیری پیشنهادی دریافت کنید.

## مشارکت

خوش‌آمدید. با تشکر از مشارکت شما برای بهبود دستورالعمل‌ها یا منابع مرجع .
